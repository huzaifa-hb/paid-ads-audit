# Campaign concepts and copy brief

Create a `campaign-brief.md` from the brand profile, objective, audience, offer, active
platforms, and current audit evidence.

## Workflow

1. Use `brand-profile.json` when present. If absent and a brand website is available,
   automatically run the brand-DNA workflow; otherwise request the missing brand context.
2. Use current audit findings when available and label concepts as generalized when not.
3. Read `references/copy-frameworks.md`, applicable platform specifications, and the
   matching industry plan asset only.
4. Run the creative-strategist role followed by the copy-writer role. These stages are
   sequential because copy depends on the selected concepts. Codex may delegate each
   stage; ChatGPT runs them inline.
5. The coordinator writes one brief containing strategy, concepts, platform placements,
   generation-ready visual jobs, and a platform-compliant copy deck.

Every concept includes objective, audience insight, angle, promise, proof, offer, funnel
stage, platform, visual direction, ratio/dimensions, copy zone, constraints, headlines,
primary text, descriptions, CTA, and character-count validation. Do not claim guaranteed
performance. Continue automatically into native image generation when the user asked for
finished creatives, not merely a brief.
