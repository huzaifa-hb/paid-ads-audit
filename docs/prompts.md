# Example prompts

Copy any of these into ChatGPT or Claude after installing the skill. Change the numbers to yours. In Claude Code you can also use the slash commands shown.

## Full audit

```
Audit my paid ads. Ecommerce, supplements, $42k/month: Meta $28k, Google $12k,
TikTok $2k. Goal is purchases at 2.5 ROAS blended. Last 30 days vs prior 30.
Exports attached.
```
Claude Code: `/ads audit`

## One platform

```
Deep dive on Google Ads only. B2B SaaS, $9k/month, goal is demo requests at
$180 CPA or better. Campaign, keyword, and search terms exports attached,
plus a screenshot of my conversion actions.
```
Claude Code: `/ads google`, `/ads meta`, `/ads youtube`, `/ads linkedin`, `/ads tiktok`, `/ads microsoft`, `/ads apple`

## Creative and fatigue

```
Which of my Meta ads are fatigued and what should I replace them with?
Ad-level export with frequency and CTR attached. Skincare, purchase goal.
```
Claude Code: `/ads creative`

## Landing page

```
Review this landing page for paid traffic: https://example.com/offer
Traffic is Meta cold audiences, mobile-heavy, goal is a $49 purchase.
```
Claude Code: `/ads landing`

## Budget and bidding

```
I have $25k/month across Meta and Google. Google is at 4.1 ROAS on $8k,
Meta at 2.2 ROAS on $17k. Break-even ROAS is 1.8. How should I reallocate,
and how fast can I scale without breaking learning?
```
Claude Code: `/ads budget`

## Media plan

```
Build a 90-day paid media plan for a local HVAC company with $6k/month.
Goal is booked calls. We have never run ads.
```
Claude Code: `/ads plan local-service` (other templates: `ecommerce`, `saas`, `b2b-enterprise`, `info-products`, `mobile-app`, `real-estate`, `healthcare`, `finance`, `agency`, `generic`)

## Competitor research

```
What are my three biggest competitors running on Meta and Google right now?
Brands: X, Y, Z. We sell mid-price running shoes.
```
Claude Code: `/ads competitor`

## Math

```
AOV is $84, gross margin 62%, refund rate 6%, repeat purchase adds 30% LTV.
What is my break-even CPA and ROAS, and what target should I set to hit
20% net margin on ad spend?
```
Claude Code: `/ads math`

## A/B test design

```
I want to test a new hook on Meta. Current CVR is 2.1% on about 900
purchases a month. How big a lift can I detect in two weeks, and how
should I set the test up?
```
Claude Code: `/ads test`

## Client report

```
Turn the audit above into a client-ready PDF report. Agency is Acme Media,
client is Northwind Outdoor. Keep it to executive summary, scorecard,
top ten actions, and appendix.
```
Claude Code: `/ads report`

## Creative production

```
Pull the brand profile from https://example.com, then draft three campaign
concepts for a Meta prospecting push with headlines and primary text.
```
Claude Code: `/ads dna https://example.com`, then `/ads create`, then `/ads generate` for images and `/ads photoshoot` for product shots. Image generation in the Claude version needs an image provider configured; the skill tells you what to set up if one is missing.
